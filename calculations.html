1.1 Cache 平均访问时间
Cache · Average Access Time
交互可视化 · 命中率滑块 → T 实时变化
单层 Cache
T = h · Tc + (1 − h) · Tm
分层 Cache（先 L1 再 L2 再主存）
T = h₁ · Tc₁ + (1 − h₁) · [h₂ · (Tc₁+Tc₂) + (1−h₂) · (Tc₁+Tm)]
▸ 典型题
Cache 访问 10 ns，主存 100 ns，命中率 90%。
T = 0.9 × 10 + 0.1 × 100 = 19 ns
陷阱：分层 Cache 不要漏算前级的访问时间（先查 L1 不命中才会查 L2）。

1.3 系统可靠性
×2真题考过2022·2023下
Reliability · Series / Parallel
交互可视化 · 串/并/N模冗余 三选一对比
串联（一个挂全挂）
R = R₁ · R₂ · … · Rn
并联（备份互为冗余）
R = 1 − (1−R₁)(1−R₂)…(1−Rn)
N 取 K 表决（K 个正常工作即可）
R = Σi=K..N C(N,i) · Rⁱ · (1−R)^(N−i)
▸ 典型题
3 个 R=0.9 模块串联：R = 0.9³ = 0.729
3 个 R=0.9 模块并联：R = 1−0.1³ = 0.999
铁律：串联降可靠，并联升可靠——多数题目要你识别结构（混合串并联要分层计算）。
历年真题
2023下 综合·单选 串/并联
题干某系统由 4 个独立子系统组成，每个子系统可靠度均为 0.9。若采用"2 个串联为一组、2 组再并联"的冗余结构，系统的可靠度约为：
答案要点
  1. 单支路串联可靠度 = 0.9 × 0.9 = 0.81
  2. 两支路并联 R = 1 − (1 − 0.81)² = 1 − 0.0361 = 0.9639
  3. 对比 4 个全串联 0.9⁴ = 0.6561，并联冗余显著提升
2022 综合·单选 可用性
题干某系统 MTBF = 2000 小时、MTTR = 2 小时，其可用性约为：
答案要点
  1. A = MTBF / (MTBF + MTTR) = 2000 / 2002 ≈ 0.999
  2. 即 99.9%（三个 9）
  3. 每年停机时间 ≈ 365×24×60×0.001 ≈ 8.76 小时
2024上 综合·单选 3 取 2 表决
题干3 个可靠度均为 0.9 的相同模块组成"3 取 2 表决系统"，系统可靠度为：
答案要点
  1. R = Σᵢ₌₂³ C(3,i)·0.9ⁱ·0.1⁽³⁻ⁱ⁾
  2. = C(3,2)·0.81·0.1 + 0.729 = 0.243 + 0.729 = 0.972
  3. 介于纯并联 0.999 与单模块 0.9 之间，比单模块可靠、比纯并联严

1.4 磁盘存取时间
×2真题考过2018下·2022
Disk Access Time
交互动画 · FCFS/SSTF/SCAN/C-SCAN 磁头轨迹对比
T存取 = T寻道 + T旋转等待 + T传输
T旋转等待 = 旋转周期 / 2 （随机分布）
T传输 = 数据量 / 传输速率
调度算法特点
FCFS先来先服务，简单但慢
SSTF最短寻道优先，可能远道饿死
SCAN电梯算法，往返扫描
C-SCAN单向扫描，回到 0 再来
历年真题
2025下 综合·单选 SSTF
题干假设磁盘移动臂位于 21 号柱面，磁道请求序列为 ④⑤②①⑥③⑧⑨⑦（柱面号），若采用最短移臂（SSTF）调度算法，系统的响应序列应为：
答案要点
  1. 起点 21，每次选距当前位置最近的磁道
  2. 典型访问序列：21→④→⑤→②→①→⑥→③→⑧→⑨→⑦
  3. 关键点：每次从剩余请求中找与当前磁头差值最小的磁道
2022 综合·单选 存取时间
题干某磁盘转速 6000 RPM（转/分钟），平均寻道时间 8 ms，每扇区读 0.5 ms，则读取一个扇区的平均存取时间约为：
答案要点
  1. 旋转周期 = 60000 / 6000 = 10 ms，平均旋转等待 = 10/2 = 5 ms
  2. T存取 = T寻道 + T旋转 + T传输 = 8 + 5 + 0.5 = 13.5 ms
  3. 传输时间常忽略（数量级远小于寻道/旋转）
2018下 综合·单选 SCAN/C-SCAN
题干下列磁盘调度算法中，能保证每个磁道请求的等待时间相对最公平（即不会出现远端磁道长期得不到服务）的是：
答案要点
  1. SSTF 存在"饿死"风险——远端请求可能一直等
  2. SCAN / C-SCAN 类似电梯算法，磁头往返或单向扫描，公平性最好
  3. FCFS 绝对公平但效率最低；C-SCAN 比 SCAN 更均匀（无中间回扫的加速）
来源：综合知识真题回忆版 · 涵盖 SSTF、SCAN、磁盘存取时间三类常考

1.6 子网划分
Subnetting & VLSM
交互可视化 · 32 位色带 + 子网段实时划分
地址分类（A/B/C/D/E）
A 类：1.0.0.0 ~ 126.255.255.255 / 8 主机 2²⁴ − 2
B 类：128.0.0.0 ~ 191.255.255.255 / 16 主机 2¹⁶ − 2
C 类：192.0.0.0 ~ 223.255.255.255 / 24 主机 2⁸ − 2
子网数（借位）
子网数 = 2^(借位数)

/n → 前 n 位为 1，后 (32−n) 位为 0

▸ 典型题
C 类 192.168.10.0，要划分 4 个子网：
借位 = log₂4 = 2 位 → /26
子网掩码 = 255.255.255.192
每子网主机 = 2⁶ − 2 = 62 台
子网：0、64、128、192（每段 64）

第 1 步 · 掩码换算
255.255.255.248 → 11111111.11111111.11111111.11111000  →  /29
前 29 位为网络/子网位，后 3 位为主机位
第 2 步 · 32 位地址结构

24 位

5 位
主机位
3 位
主机位 = 32 − 29 = 3 位，每子网含 2³ = 8 个地址（网络号 1 + 主机 6 + 广播 1）。

1.9 位示图（位向量）
×4真题考过2018下·2020·2025上·2026上
Bitmap for Free Block Management
交互可视化 · 位矩阵 + 字号/位号联动
空闲 (0) 已分配 (1) 高亮 (字号b,位号j) 不可用边界
位示图大小
总位数 = 磁盘块数 = 柱面数 × 盘面数 × 每面扇区数
每 1 位对应 1 个磁盘块（0=空闲，1=已分配）
占用字节数
B = ceil(总位数 / 8) 字节
块号 ↔ 位号转换
字号 = (块号 − 1) DIV 32 （每字 32 位）
位号 = (块号 − 1) MOD 32
字号 b、位号 j → 物理块号
块号 = b × 32 + j + 1
▸ 典型题
磁盘 200 柱面 × 10 盘面 × 200 扇区 = 400 000 块
位示图占字节 = 400 000 / 8 = 50 000 字节
字号 100、位号 20 → 块号 = 100×32 + 20 + 1 = 3221 块
陷阱：从 1 开始计数要记得 +1；公式里块号和位号差 1。
历年真题
2025上 综合·单选 位示图大小
题干某系统对空闲存储空间管理采取位示图方式，每页（物理块）大小 4KB，总存储容量 16GB，则位示图大小为（）KB。
答案要点
  1. 物理块数 = 16GB / 4KB = 4M 块 = 2²² 块
  2. 位示图共需 4M bit = 4M / 8 字节 = 512 KB
  3. 常考坑：忘记把 bit 转成 byte（÷8）
2020 综合·单选 位示图字数
题干某计算机字长 32 位，文件系统采用位示图管理磁盘空间。磁盘容量 300GB，物理块大小 4MB，则位示图大小为（）字。
答案要点
  1. 物理块数 = 300GB / 4MB = 76800 块
  2. 位示图位数 = 76800，每字 32 位
  3. 位示图字数 = 76800 / 32 = 2400 字
2018下 综合·单选 多级索引
题干文件系统采用多级索引结构，块大小 4KB，块号占 4 字节。二级索引结构下文件最大占用（）物理块。
答案要点
  1. 每块可容纳的块号数 = 4KB / 4B = 1024 个
  2. 一级索引 = 1024 块
  3. 二级索引 = 1024 × 1024 = 1 048 576 块（≈1GB）
  4. 与位示图无关，本质是块号索引块的容量
2026上 综合·单选 字号位号
题干某位示图共 8000 位，每字 32 位。求字号 100、位号 15 对应的物理块号：
答案要点

  2. 块号 = 100 × 32 + 15 + 1 = 3216

1.10 页式存储地址结构
×3真题考过2019下·2021·2025下
Paging · Page Number + Offset
交互可视化 · 地址拆分 + 页表点击查映射
▸ 页表（点击任一项查映射）
逻辑地址 = 页号 P + 页内偏移 W
页号位数 = log₂(页数)
页内偏移位数 = log₂(页大小)
物理地址 = 物理块号 + 页内偏移
物理地址 = f(页号) × 页大小 + 页内偏移
f(页号) = 页表查得的物理块号
总位数换算
页表项数 = 2^(页号位数)
页表大小 = 页表项数 × (每项位数 / 8)
缺页率
f = 缺页次数 / 总访问次数
平均访问时间（含快表 TLB）
T = h·tTLB + (1−h)·(tTLB + tM) + tM
h = TLB 命中率，tM = 访问主存时间
▸ 典型题
逻辑地址 32 位，页大小 4 KB = 2¹² 字节
页内偏移 = 12 位 → 页号 = 32 − 12 = 20 位
页数 = 2²⁰ = 1M 页
物理地址 32 位 → 物理块号 = 32 − 12 = 20 位
页表大小 = 2²⁰ × 4 B = 4 MB
陷阱：页大小是 2 的幂（如 4K/8K/16K），偏移位数才是 log₂；混淆位数会全错。
历年真题
2019下 综合·单选 页表映射
题干进程 P 有 8 个页面（0~7），页面大小 4KB，分配 4 个存储块。已知页表：1、2、5、7 号页在内存，对应页帧号 7、5、3、9。则逻辑地址 5148H 变换后的物理地址为（ ）。
答案要点
  1. 5148H = 0x5148 = 20808；页大小 4KB = 2¹²，页号 = 20808 ÷ 4096 = 5（页号 5）
  2. 查表：5 号页对应页帧号 3；页内偏移 = 20808 − 5×4096 = 328
  3. 物理地址 = 3 × 4096 + 328 = 12288 + 328 = 12616 = 3148H
  4. 易错：直接 5148H 当十六进制页号（先转十进制再除页大小）
2021 综合·单选 地址变换
题干页面大小 4K，进程 P1 逻辑地址 1B1AH 经页表变换后对应的物理地址（十六进制）是：
答案要点
  1. 1B1AH = 0x1B1A = 6938；页号 = 6938 ÷ 4096 = 1（页号 1），页内偏移 = 6938 − 4096 = 2842 = 0xB1A
  2. 查页表得 1 号页对应块号 F（由题给）
  3. 物理地址 = F × 4096 + 0xB1A
  4. 关键步骤：先把十六进制逻辑地址转十进制（或直接按位切），再查表
2025下 综合·单选 页表项数
题干某系统采用页式管理，逻辑地址 32 位、页大小 4KB、页表项占 4 字节，则该进程的页表占用字节数为：
答案要点
  1. 页内偏移 12 位 → 页号位数 = 32 − 12 = 20 位
  2. 页表项数 = 2²⁰ = 1M
  3. 页表大小 = 1M × 4B = 4 MB

1.12 页面置换（OPT/FIFO/LRU）
×1真题考过2019下
Page Replacement Algorithms
交互动画 · 三算法并排逐步演示
改输入即自动刷新，▶ 单步逐步演示

OPT 缺页: 0

FIFO 缺页: 0

Belady 异常
FIFO 在特定引用串下：页框数 ↑，缺页次数反而 ↑
算法思路特点
OPT未来最久不用理论最优，不可实现
FIFO先进先出可能出现 Belady 异常

改进型 CLOCK / NRU访问位 + 修改位 4 类别优先淘汰 (0,0)，减少磁盘写
改进型 Clock（NRU）· 4 类别优先级
同时使用 访问位(R) 与 修改位(M)，把内存页分 4 类，按下表优先级淘汰：
优先级访问位 R修改位 M含义淘汰代价
① 最先淘汰 00未访问、未修改（干净） 直接丢弃，无须写回磁盘
② 次先淘汰 01未访问、已修改（脏） 需先写回再淘汰
③ 较次 10已访问、未修改 最近用过，直接丢弃
④ 最后淘汰 11已访问、已修改 既常用又脏，代价最高
▸ 典型题 · 改进型 Clock 淘汰判断
内存中 4 个页面的访问位 / 修改位如下：
页面号访问位修改位类别
111④ 已访问 + 已修改
210③ 已访问 + 未修改
301② 未访问 + 已修改
400 ① 未访问 + 未修改
答案：淘汰页面 4。理由：① 类（访问位 0、修改位 0）代价最小， 既不常用又是干净页，直接丢弃即可，省一次磁盘写回。
为什么修改位很重要
淘汰 未修改 页：直接丢弃，0 次磁盘写
淘汰 已修改 页（脏页）：必须先写回，1 次磁盘写

1.13 银行家算法
×1真题考过2025上
Banker's Algorithm for Deadlock Avoidance
交互器 · 编辑 Max/Allocation 矩阵 + 自动跑安全算法
核心矩阵
Max[i,j] = 进程 i 对资源 j 的最大需求
Allocation[i,j] = 已分配
Need[i,j] = Max − Allocation
Available = 总资源 − ΣAllocation
安全判定
① Work = Available，Finish[i] = false
② 找 i：Finish[i]=false 且 Need[i] ≤ Work
③ Work += Allocation[i]；Finish[i]=true；回到 ②
④ 若所有 Finish[i]=true → 安全，否则不安全
不死锁最小资源数
Rmin = N × (M − 1) + 1
N = 进程数，M = 每个进程最大需求

3.3 候选码求解
×6真题考过2019下·2024上·2024下·2025上·2025下·2026上
Candidate Key via Closure
交互可视化 · FD 有向图 + 闭包逐步推导
属性分类
闭包逐步推导
闭包法
X⁺ = 由 X 出发反复用 FD 推出的所有属性
判定流程
  1. 将只在左边出现的属性组 L（L 类）求闭包 L⁺
  2. 若 L⁺ 覆盖全部属性 → L 即候选码
  3. 否则从左右都出现（N 类）属性中试探加入
  4. 检查超集：(L∪{A})⁺ 是否覆盖全部属性
陷阱：L 类属性（只在左部）一定在候选码中；R 类（只在右部）一定不在。
历年真题
2025上 综合·单选 闭包法
题干关系模式 R(a, b, c, d)，函数依赖 F = {a→cd, c→b}，则 R 的候选码是：
答案要点
  1. 属性分类：L 类（只在左部）= {a, c}；R 类（只在右部）= {d, b}；N 类 = ∅
  2. 试探 a⁺：{a} → a→cd → {a,c,d}；加上 c→b → {a,b,c,d} = U
  3. a 是唯一候选码
  4. 速算口诀：L 类必在候选码，先求 L⁺ 再扩 N 类
2025下 综合·单选 唯一候选码
题干R(A, B, C, D, E)，FD = {A→BC, B→D, D→E}，则：
答案要点
  1. A⁺ = {A} + A→BC → {A,B,C} + B→D → {A,B,C,D} + D→E → {A,B,C,D,E} = U
  2. A 是唯一候选码，R 属于 2NF 但不属于 3NF（A→B→D→E 传递依赖）
2026上 综合·单选 L 类属性
题干R(SNO, CNO, SN, CN, GRADE)，FD = {SNO→SN, CNO→CN, (SNO,CNO)→GRADE}，候选码为：
答案要点
  1. L 类 = {SNO, CNO}（只在左部）；R 类 = {SN, CN, GRADE}
  2. (SNO,CNO)⁺ = 全部属性 → 候选码 = (SNO, CNO)
  3. 注意：候选码可能是属性组合（多属性），不一定是单属性
2024上 综合·单选 最小依赖
题干R(A,B,C,D,E,F)，FD = {AB→C, C→D, D→E, E→F, F→A}，该关系共有多少个候选码？
答案要点
  1. 本题 FD 形成一个循环 AB→C→D→E→F→A（回到 AB 通过 F→A 和 AB→C）
  2. 所有属性相互依赖，因此单属性 B 无法决定全部，A 必须与其他属性组合
  3. 解法：枚举最小依赖集发现至少 2 个候选码（如 BE 和 BD）
  4. 实战：先 L/N/R 分类，再分别试探；不能漏 N 类的所有组合

3.4 分解原则
×1真题考过2024上
Lossless & Dependency-Preserving
交互判定器 · 输入 R₁/R₂ + FD 集自动判无损 + 保持依赖
无损连接（充要条件）
(R₁ ∩ R₂) → (R₁ − R₁∩R₂) 或
(R₁ ∩ R₂) → (R₂ − R₁∩R₂)
保持依赖
F⁺ = (F₁ ∪ F₂ ∪ … ∪ Fn)⁺ 必须等于原 F⁺
分解目标能否同时
3NF同时保证无损 + 保持依赖
BCNF保证无损，可能破坏依赖保持
答题铁律：分解到 3NF 要写"既保持依赖又无损"；BCNF 要写"无损但可能损失依赖"。
历年真题
2024上 综合·单选 无损判定
题干分解 ρ = {AB, BC}，F = {A→C, C→B, B→A}，下列关于分解性质的描述正确的是：
答案要点
  1. R₁∩R₂ = {B}；B → R₂−B = {C}（因 C→B 等价 B→C）
  2. 满足 (R₁∩R₂) → (R₁−R₁∩R₂) 或 → (R₂−R₁∩R₂) → 无损连接 ✓
  3. F 在 R₁, R₂ 上的投影 = {A→C, B→A} ∪ {C→B} = F → 保持依赖 ✓
  4. 结论：ρ 既有无损连接又保持依赖，是 R 的优秀分解
2024下 综合·单选 3NF 分解
题干R(A,B,C,D)，F = {A→B, B→C, C→D}，下列分解中属于 R 的 3NF 无损保持依赖分解的是：
答案要点
  1. 按 3NF 合成算法：每个 FD 一对一子模式 → R1(A,B), R2(B,C), R3(C,D)
  2. A⁺ = {A,B,C,D} = U，A 是候选码 → 加 R4(A) 或合并到 R1
  3. ρ = {R1(A,B), R2(B,C), R3(C,D)}（候选码 A 已含在 R1）
  4. 验证无损：相邻交集传递，B→C, C→D, A→B 保持所有依赖 → ✓
2025上 综合·单选 BCNF 缺陷
题干关于 BCNF 分解与 3NF 分解的关系，下列说法正确的是：
答案要点
  1. 3NF 分解可同时保证无损连接 + 保持依赖
  2. BCNF 分解一定保证无损连接，但 可能破坏依赖保持
  3. 实战策略：先 BCNF 分解（消除异常），若丢失依赖再加回"补救"子模式

4.1 关键路径法 CPM
×7真题考过2018下·2019下·2022·2023下·2024上·2024下·2025上
Critical Path Method
交互计算器 · A→B→C 与 A→D→C 双路径
提示：节点可拖拽；关键路径红色虚线流动动画。
节点时间参数
ES = max(前置 EF) ← 最早开始
EF = ES + 工期 ← 最早完成
LF = min(后续 LS) ← 最晚完成
LS = LF − 工期 ← 最晚开始
TF = LS − ES = LF − EF ← 总时差
FF = 后继 ES − EF ← 自由时差
关键路径特征：TF=0 的活动组成的路径；可能有多条；决定项目工期。
▸ 计算顺序
  1. 正向算 ES / EF（从左到右）
  2. 反向算 LF / LS（从右到左）
  3. 求 TF = LS − ES（=0 即关键活动）
  4. 串联 TF=0 的活动 → 关键路径
历年真题
2025上 综合·单选 关键路径
题干某项目网络图：A→B→G→H，B→H，C→H 等。若 B=5, G=6, H=4，A→B=3、B→G=2、B→H=4，求项目最短工期：
答案要点
  1. 路径 1：A→B→G→H = 3 + 5 + 2 + 4 = 14 天
  2. 路径 2：A→B→H = 3 + 5 + 4 = 12 天
  3. 关键路径 = 工期最长的路径（14 天）
  4. 常考套路：列所有路径 → 求各路径工期 → 取最大值
2024下 综合·单选 赶工压缩
题干关键路径工期 11 天，项目经理希望压缩到 6 天。已知各工序赶工 1 天费用不同，下列压缩方式正确的是：
答案要点
  1. 工期压缩两种：赶工（加资源 → 加成本） / 快速跟进（串行改并行 → 加返工风险）
  2. 只能压缩关键路径上的活动
  3. 压非关键路径无效——即使它变短也不影响总工期
  4. 多关键路径时需要同步压缩各关键活动，否则新路径变成关键
2019下 综合·单选 时差计算
题干网络图中某活动 TF=3 天，FF=1 天，下列推断正确的是：
答案要点
  1. 总时差 TF：不影响项目总工期的前提下可拖延的时间
  2. 自由时差 FF：不影响紧后活动最早开始的前提下可拖延
  3. 关系：FF ≤ TF
  4. 结论：延迟 1 天不影响紧后；延迟 3 天以内不影响总工期；超过 3 天则拖期

4.3 挣值管理 EVM ⭐必考
×N真题考过案例 T3/T4 必考
Earned Value Management
交互计算器 · 输入四个值自动算 EAC/ETC/VAC
进度偏差 SV
SV = 0
成本偏差 CV
CV = 0
三个基础值
PV = Planned Value 计划值
EV = Earned Value 挣值（已完成工作的预算）
AC = Actual Cost 实际成本
偏差
SV = EV − PV (>0 超前，<0 落后)
CV = EV − AC (>0 节约，<0 超支)
绩效指数
SPI = EV / PV (>1 超前，<1 落后)
CPI = EV / AC (>1 节约，<1 超支)
预测公式
BAC = 完工预算
EAC = BAC / CPI ← 典型性差异
ETC = EAC − AC
VAC = BAC − EAC ← 完工偏差
▸ 典型题
计划 10 万，AC=5.5 万，完成了 PV=5 万对应的 EV=4 万
SV = 4−5 = −1（落后）
CV = 4−5.5 = −1.5（超支）
SPI = 0.8，CPI = 0.73
EAC = 10 / 0.73 ≈ 13.7 万
陷阱：题目常给"完成 50%"、"完成 100% 的 40%"，要先把 EV 算出来再用。
历年真题
2024下·综合 经典变形 EVM 四指标计算
题干项目计划工期 100 天、BAC=200 万。第 60 天检查：EV=100 万、AC=120 万、PV=110 万。下列指标计算**错误**的是（　）
答案要点
  1. CV = EV − AC = 100 − 120 = −20 万（超支）✓
  2. SV = EV − PV = 100 − 110 = −10 万（滞后）✓
  3. CPI = EV/AC = 100/120 ≈ 0.83（<1 效率低）✓
  4. EAC = BAC + AC = 320 万 ✗ 错误！典型差异下 EAC = BAC/CPI ≈ 200/0.83 ≈ 241 万
  5. 故选 D
案例·常考 完工估算 EAC EAC 公式选择
题干某项目进行到第 8 个月，BAC=200 万，已完成 40% 工作量（EV=80 万），实际花费 AC=100 万，剩余工作将按当前效率完成，求 EAC 和 ETC。
答案要点
  1. CPI = EV/AC = 80/100 = 0.8（<1，效率低）
  2. 典型差异下 EAC = BAC/CPI = 200/0.8 = 250 万
  3. ETC = EAC − AC = 250 − 100 = 150 万
  4. VAC = BAC − EAC = 200 − 250 = −50 万（最终超支 50 万）

5.3 敏感 / 权衡 / 风险点
Sensitivity / Tradeoff / Risk Point
◉
敏感点
影响一个质量属性的单个决策
答题关键词：对性能有重大影响 / 对可用性是关键 / 是 A 属性的决定性因素

⇄
权衡点
影响多个质量属性，且这些属性之间存在矛盾

⚠
风险点
存在潜在问题的架构决策，需要降低或消除
答题关键词：可能导致 / 存在 ... 风险 / 建议采用 ... 缓解

案例：单点故障可能导致系统不可用，建议采用主从热备。
✓
非风险点
已经分析过无问题的决策，可放心采用
答题关键词：已分析 / 不存在风险 / 可放心采用 / 满足 ... 要求

案例：bcrypt + salt 已分析无安全风险。
术语定义答题关键词
敏感点影响一个质量属性的决策对性能有重大影响
权衡点影响多个质量属性的决策A↑则 B↓
风险点有潜在问题的决策可能导致...
非风险点已分析无问题可放心采用
▸ 答题模板
风险点：X 方案可能导致 A 性能瓶颈，建议采用 Y 方案。
权衡点：使用缓存会提升性能（响应时间↓），但降低数据一致性（数据安全↓）。
陷阱：风险点 ≠ 不好的点；要写成"决策+风险+建议"。

6.1 信道容量

Nyquist & Shannon
双公式对比 · 奈氏（无噪声）+ 香农（有噪声）+ dB 换算
奈奎斯特（无噪声）
0 bps
C = 2W · log₂(N) = 2 × 3000 × log₂(4)
香农（有噪声上限）
0 bps
C = W · log₂(1 + S/N) = 3000 × log₂(1 + 1000)
💡 奈氏是理论速率，香农是噪声环境下的实际上限。 二者取小 = 工程可用带宽。
⚠ dB ↔ 线性换算：S/N（线性）= 10^(dB/10)。例：30 dB → 1000 倍。
奈奎斯特定理（无噪声）
C = 2W · log₂(N)
W = 带宽 Hz，N = 信号级数
香农定理（有噪声）
C = W · log₂(1 + S/N)
S/N = 信噪比，dB 表示
区分：奈氏用于理想无噪声；香农用于有噪声上限；考试二者给单位（bit/s）。
陷阱：S/N 给的是 dB 值时先换算：S/N（线性）= 10^(dB/10)。
历年真题
2025上·综合 14 单选 奈奎斯特定理
题干信道带宽 3000Hz，信号 32 种状态，无干扰条件下最大传输速率为（　）kbps
答案要点
  1. 无噪声 → 用奈奎斯特：C = 2W · log₂(N)
  2. C = 2 × 3000 × log₂(32) = 6000 × 5 = 30000 bps = 30 kbps
  3. 故选 B. 30 kbps
2024上·综合 经典计算 香农定理 + dB 换算
题干带宽 W=3000Hz，信噪比 S/N = 30 dB，求信道最大传输速率。
答案要点
  1. 30 dB → 线性 S/N = 10^(30/10) = 1000 倍
  2. 有噪声 → 用香农：C = W · log₂(1 + S/N) = 3000 · log₂(1+1000)
  3. log₂(1001) ≈ 9.97 → C ≈ 3000 × 9.97 ≈ 30 kbps
  4. 本题奈氏与香农结果相近 → 工程上常取两者最小值
2024下·综合 54 单选 提升信道容量
题干信道容量是信道的最大传输速率，可以通过（　）提升信道容量。
答案要点
  1. 香农：C = W · log₂(1 + S/N) — 与 W、S/N 均正相关
  2. 加大带宽或提高信噪比都提升容量
  3. W 增大的效果 > S/N 降低的影响 → 选 A 或 C
  4. 原题答案指向 C（带宽增大足以补偿信噪比降低）
常考辨析 公式选择 奈氏 vs 香农
题干某信道带宽 4 kHz，信号 16 级，无噪声最大传输速率为（　）bps；引入 30 dB 信噪比噪声后，最大传输速率为（　）bps（取香农）。
答案要点
  1. 无噪声（奈氏）：C = 2 × 4000 × log₂(16) = 8000 × 4 = 32000 bps
  2. 30 dB → 1000 → 香农 C = 4000 × log₂(1001) ≈ 4000 × 9.97 ≈ 39880 bps
  3. 两者取小作为工程可用带宽（约 32 kbps）
  4. 记忆口诀：奈氏看级数，香农看噪声

Performance & Capacity · 案例高频
交互计算器 · 漏斗式自动算机器数
流量估算三步法
  1. PV = 日活用户数 × 每人每天访问次数
  2. 平均 QPS = PV / 86400（按全天）

平均 QPS = PV / 86400
峰值 QPS = 平均 QPS × 峰值倍数
机器数 = ceil(峰值 QPS / 单机 QPS)
单机带宽 (bps) = 页面平均大小 × 单机 QPS × 8
存储量 (GB) = (PV × 页面平均 KB) / 1024 / 1024
常见经验值
指标参考值
普通 Web 页面200 KB（不含图片）/ 1-2 MB（含图）
